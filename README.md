# インフレ餃子 🥟

数字がデカいほうが勝つ、頭を使わない 3D の iOS ゲームです。
指を左右に動かしてゲートをくぐり、餃子の群れを増やして、最後に巨大なボスへ体当たりします。

- 片手・縦画面・1 プレイ 20〜30 秒
- 餃子の数は 万 → 億 → 兆 → … → 無量大数 → ∞ までインフレします
- 3D モデル・画像・音声ファイルは 1 つも入っていません(立体はコードで組み立て、音はコードで合成)
- 広告・課金・通信・トラッキングなし

## 遊び方

1. タイトル画面をタップしてスタート
2. 指を左右にスライドして、左右どちらかのゲートを選ぶ
   - 青いゲート(`+` `×` `2乗`)は増える
   - 赤いゲート(`−` `÷` `√`)は減る
   - 紫の `？？？` は通るまで中身が分からない
   - 敵の群れにぶつかると、書いてある数だけ減る
3. 最後にボスへ突撃。餃子の数がボスの HP 以上なら勝ち
4. 勝つとコインがもらえる。ショップでスキンを買える(全 8 種)

増やし続けるとコンボがつながり、もらえるコインが増えます。
画面上部の「🎯 ボス HP」に ✅ がつけば、そのままボスに勝てます。

音は本体の消音スイッチ(サイレントモード)に従います。鳴らないときは消音を解除してください。

## わざと入れてあるバグ(修正予定なし)

このゲームには意図的にバグを残してあります。自力で見つけたい人はここから先を読まないでください。

<details>

| バグ | 起こし方 | 何が起きるか |
| --- | --- | --- |
| 裏世界 | 引き算や敵で 0 を飛び越えてマイナスにする | 全滅せず、全員が逆立ちした裏世界に入る。ボスは絶対値で判定されるので、ここでは引き算と敵が味方になる |
| ちょうど 0 だけ全滅 | 数をぴったり 0 にする | これだけは本当に全滅する。マイナスなら生きている |
| NaN 化 | 裏世界で `√` をくぐる(まれに `NaN` ゲートも出る) | 数ではなくなり、全員が骨組みだけの姿になる。NaN はどんなボスにも必ず勝つが、コインに換金できない(0 枚) |
| 2 乗で生還 | 裏世界で `2乗` をくぐる | 表世界に戻る |
| 壁抜け増殖 | 画面の端に向かって指を動かし続ける | 反対側の端にワープして数が 2 倍になる(1 レベルに 2 回まで) |
| 巻き戻り | 下へ素早くフリックする | 少しだけ逆走する。通過済みのゲートをもう一度くぐれる(1 レベルに 2 回まで) |
| コイン連打 | リザルトでコインが数え上がっている間にコインを連打する | 叩いた分だけコインが増える |
| 消し忘れデバッグメニュー | タイトル画面下のバージョン表記を 7 回タップ | コイン追加、ボス HP を 1 にする、レベルスキップ |
| 帰ってくるボス | 倒す | 吹っ飛んだボスがたまに空から落ちてきて、転がって去っていく(無害) |
| 全員うしろ向き | 何もしなくてよい | 餃子たちは全員カメラ目線のまま後ろ向きに走っている(無害) |
| 文字化け | 何もしなくてよい | リザルトの見出しがたまに一瞬だけ文字化けする(無害) |
| ゲートの色が嘘 | 裏世界に入る | 青 = 良い、赤 = 悪いの色分けが裏世界では逆なのに直っていない |

## ipa の入手とインストール

Mac も Apple Developer 登録も不要です。GitHub Actions が未署名の ipa を作ります。

### 1. ipa をダウンロードする

1. このリポジトリの **Actions** タブを開く
2. 一番上の成功している(緑の)**Build unsigned IPA** の実行を開く
3. ページ下部の **Artifacts** から `InflaGyoza-unsigned-ipa` をダウンロードする
4. zip を展開すると `InflaGyoza-unsigned.ipa` が出てくる

手動でビルドし直したいときは、Actions タブの **Build unsigned IPA → Run workflow** を押します。

### 2. iPhone に入れる

未署名の ipa はそのままでは入りません。次のどれかのツールで、自分の Apple ID を使って署名しながら入れます。

- **Sideloadly**(Windows / Mac): ipa をドラッグして Apple ID を入力し、Start を押す
- **AltStore**(Windows / Mac): AltServer を入れて、iPhone の AltStore から ipa を開く

入れたあと、iPhone の **設定 → 一般 → VPN とデバイス管理** で自分の Apple ID を信頼します。
iOS 16 以降では **設定 → プライバシーとセキュリティ → デベロッパモード** をオンにする必要があります。

無料の Apple ID で署名した場合、7 日で期限が切れるので入れ直しが必要です。

## 中身

```
GameCore/            ゲームのルール(描画なしの Swift パッケージ)とユニットテスト
App/                 3D の世界(SceneKit)、その上に重ねる UI(SpriteKit)、コード合成の音、触覚
Config/Info.plist    アプリの設定
project.yml          XcodeGen の定義(.xcodeproj はコミットしない)
scripts/make_icon.py アイコン生成スクリプト
.github/workflows/   未署名 ipa をビルドするワークフロー
```

- ルール(ゲートの計算、難易度、報酬、セーブ)は `GameCore` に分けてあり、`swift test --package-path GameCore` でテストできます
- レベルは番号から決定的に生成されるので、同じレベルは誰が遊んでも同じ配置です。
  「大きくなる方を選び続ければ必ず勝てる」ことをレベル 1〜300 についてテストしています
- 対応は iOS 16 以上、iPhone 縦画面のみ

## Mac でビルドする場合

```sh
brew install xcodegen

```
